Which graph library for the Studio canvas?

All three can replicate the yFiles knowledge-graph look. Pick the one whose trade-offs fit best.

A

React Flow

The de-facto React graph library. Drag nodes, pan/zoom, custom node renderers, mini-map, edge routing — all built in. Looks great out of the box and integrates cleanly with the existing React + Tailwind stack. ~200 KB gzipped.


Best for: DAG / directed graphs (exactly what TraceGraph is). Rich ecosystem with plugins. MIT licensed.

Trade-off: Node positions still need an initial layout algorithm (you can use dagre or elkjs alongside it). Not free for commercial SaaS use in the Pro tier, but the core library is MIT.

B

Cytoscape.js

Battle-tested graph library used in bioinformatics, network tools, and knowledge graphs. Built-in layout algorithms (dagre, cola, elk, breadthfirst). Handles very large graphs efficiently. ~150 KB.


Best for: Graphs where you want the library to own layout completely. Very close to what yFiles demos show.

Trade-off: Not React-native — needs a wrapper (react-cytoscapejs). Custom node rendering is limited compared to React Flow (no arbitrary JSX in nodes).

C

D3-force + custom SVG

Build on top of D3's force simulation. Full creative control — any visual style. Smooth physics-based layout. The existing SVG canvas in Studio.tsx is already close to this approach.


Best for: Highly custom visual designs. Knowledge graph "nebula" aesthetic.

Trade-off: Most implementation work. D3's imperative mutation model fights React's rendering. Requires writing layout, interaction, and animation from scratch.

My recommendation

React Flow (A) — it integrates seamlessly with the existing React codebase, handles DAGs natively (which is exactly what a TraceGraph is), and produces the interactive node-dragging / pan-zoom / minimap experience from the yFiles demo with the least custom code. Pair it with @dagrejs/dagre for automatic hierarchical layout.
