Graph layout algorithm

How should nodes be arranged automatically?

A — Force-directed (organic)

Nodes repel each other and edges pull connected nodes together. Results in a natural cluster layout. Feels alive — nodes animate into position on load. Great for knowledge graphs with many connections.

B — Hierarchical / dagre (top-to-bottom)

Entry node at top, terminal at bottom. Edges always flow downward. Parallel branches fan out sideways. Consistent and readable for DAGs. Mirrors how you'd read a flowchart. Auto-arranged by dagre.
