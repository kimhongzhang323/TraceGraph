# 检查点与恢复



要点：

- 检查点在节点成功退出后写入，写入后再解析下一条边。
- 恢复时从 `lastCompletedNode` 开始，重新评估它的出边。
- 节点必须是幂等的或使用 `idempotencyKey()`。

示例：启用 `CheckpointStore` 的运行流程

1. 节点 A 成功退出，执行器在事务中写入检查点（lastCompletedNode = A）。
2. 进程崩溃或重启。
3. 恢复时，执行器加载检查点，重新评估 A 的出边并继续执行。

注意：因为恢复会重新评估出边，依赖外部系统的边谓词必须是纯函数（只能依赖状态，不应做外部请求）。

练习：在本地配置一个简单的 `InMemoryCheckpointStore`，运行一个包含长时 sleep 的图，强制终止进程并恢复，观察执行恢复点。
