# 检索增强生成 (RAG)

检索增强生成 (RAG) 是一种强大的模式，通过外部知识来丰富大语言模型 (LLM)。TraceGraph 提供了专用的节点和模式，可轻松构建 RAG 管道。

## 文档加载和分块

您可以创建一个图，首先从各种来源加载文档。然后使用 `ChunkingNode` 将这些文档分成较小的块。

## 嵌入和向量存储

TraceGraph 集成了多种嵌入模型和向量数据库。一个典型的 RAG 图将会：
1. 嵌入传入的用户查询。
2. 在向量存储中搜索相似的块。
3. 将检索到的块注入到 LLM 的上下文中。

## 构建 RAG 图

使用 TraceGraph 构建 RAG 允许您添加复杂的路由，例如：
- 如果没有找到结果，则使用回退查询。
- 如果 LLM 确定检索到的上下文不足，则进行自我纠正循环。
- 根据中间答案微调搜索的多步检索路径。
