# 状态与上下文

在 TraceGraph 中，图的执行是由状态（State）驱动的。状态是一个贯穿所有节点的数据结构，在每一步被读取和修改。

## 图状态 (Graph State)

您可以通过创建一个类（例如 `MyState`）来定义图的状态。图中的每个节点都将此状态作为输入，并返回修改后的版本或要应用的差异。这确保了状态在节点之间安全传递。

## 上下文 (Context)

虽然 State 代表正在处理的数据，但 Context（上下文）提供了执行元数据、环境变量或特定于单词运行的依赖注入钩子。节点内部可以访问 Context，以获取配置、API 密钥或日志记录器实例，而不会污染业务 State。

## 线程安全

由于图可以并发执行，TraceGraph 确保状态修改得到适当管理。在设计您的状态类时，请考虑使用不可变的数据结构，以防止在并发分支中产生副作用。
