# 连接器

连接器是预建的集成，允许 TraceGraph 与外部系统无缝交互。它们抽象了连接到各种 API 和服务所需的样板代码。

## LLM 连接器

TraceGraph 为流行的大型语言模型提供开箱即用的连接器，将其特定的 API 差异抽象为统一的 `LlmClient` 接口。
- **OpenAI 连接器:** 适用于 GPT-4 等模型，支持函数调用和流式传输。
- **Anthropic 连接器:** 适用于 Claude 模型，处理工具使用和必要的 XML 样式格式化。
- **Mock 连接器:** 一个用于在本地测试您的图而不产生 API 成本的实用工具。

## 扩展连接器

如果您需要连接到原生不支持的服务，可以通过创建自定义节点并包装底层 SDK 或 HTTP 客户端来轻松实现自己的连接器。这可确保您的图保持整洁，并与基础设施问题解耦。
