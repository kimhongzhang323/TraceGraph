# Quickstart

See the [quickstart example](https://github.com/kimho/TraceGraph/tree/main/examples/quickstart) for a runnable project.

```bash
# Clone the repo
git clone https://github.com/kimho/TraceGraph
cd TraceGraph

# Run the quickstart example (no API keys needed)
mvn -f examples/quickstart/pom.xml exec:java
```

Expected output:
```
Final greeting: Hello, TraceGraph! (SHOUTED: HELLO, TRACEGRAPH!)
```
