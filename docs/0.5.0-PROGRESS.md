# 0.5.0 progress — autonomous loop state

This file is the durable state for the 0.5.0 coding loop. Every iteration reads it
first and updates it last. Issue queue: `gh issue list --label agent-queue`.

## Loop contract

- Work one `agent-queue` issue per branch (`feat/<slug>` off fresh `origin/main`); TDD the slice.
- `scripts/verify.sh` (run via Bash) must pass before every commit; never skip hooks.
- Push and open a PR via `gh pr create`; never merge own PRs, never force-push,
  never tag/release, never edit `.github/workflows/release.yml` or repo settings.
- If a slice exceeds ~600 changed lines, stop and split the issue.
- Same root-cause failure twice → record a blocker below and move to the next issue.
- Every PR: CHANGELOG.md entry; intentional API breaks justified in the PR body
  alongside any japicmp exclusion.
